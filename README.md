# Daily Demon Suggestions (Geode v5, GD 2.2081)

All source files are in the top folder, so you can upload them to GitHub in one go.

1. Create a GitHub repository and upload every file in this folder.
2. In the repo, open the Actions tab, tap "set up a workflow yourself", paste in the contents of `workflow-copy.txt`, and commit.
3. When the build finishes, download "Build Output" from the run and unzip it to get the `.geode` file.
4. Put the `.geode` file in your Geode mods folder.
